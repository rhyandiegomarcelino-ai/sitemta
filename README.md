# MTA Marcelino Topografia e Agrimensura

Site institucional estático publicado pelo GitHub Pages.

## Publicação pelo GitHub
1. Extraia o ZIP.
2. Envie todos os arquivos e imagens para a raiz do repositório `sitemta`.
3. Faça o commit na branch configurada no GitHub Pages.
4. Em Settings → Pages, mantenha a publicação pela branch principal e pasta `/ (root)`.

O formulário prepara uma mensagem e abre o WhatsApp. Não existe backend e o site não armazena os dados preenchidos.
